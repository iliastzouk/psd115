# Υλικό αναφοράς PSD215 — Εκπαιδευτική Ψυχολογία (Fall 2026)

Διδάσκουσα (από τους τίτλους των ηχογραφήσεων): Άννα Πριντεζή · τμήματα GEG-GEH-GEI-GEJ.

## Σημειώσεις — ξεκίνα από εδώ

Τα σημαντικότερα σημεία κάθε συνάντησης, με χρόνους `[mm:ss]` για να βρίσκεις το σημείο στο βίντεο.
Βρίσκονται στο **`content/courses/psd215/notes/`** και εμφανίζονται στη σελίδα **`/psd215`** της εφαρμογής
(ενότητα «Σημειώσεις»). Νέα συνάντηση = νέο αρχείο `NN-<όνομα>.md` εκεί, με πρώτη γραμμή `# PSD215 · <τίτλος> — Σημειώσεις`.

| Αρχείο | Περιεχόμενο |
|--------|-------------|
| `01-epanalipsi-1is-synantisis.md` | Λειτουργία μαθήματος, βαθμολογία, δραστηριότητες, τελική εργασία · τι προσφέρει η εκπαιδευτική ψυχολογία · θεωρίες ανάπτυξης (Vygotsky, Piaget, Erikson, Kohlberg) |
| `02-2i-synantisi.md` | Γνωστική προσέγγιση: προσοχή, αντίληψη, μνήμη, σκέψη · συμπεριφοριστικές και κοινωνικογνωστική θεωρία (Bandura) |

## Απομαγνητοφωνήσεις (`transcripts/`)

Πλήρες κείμενο κάθε ηχογράφησης με χρονοσφραγίδες `[hh:mm:ss]`. Είναι αυτόματη απομαγνητοφώνηση (faster-whisper,
`large-v3-turbo`, τοπικά) — αναμένονται λάθη σε ονόματα και όρους. Χρήσιμη για αναζήτηση λέξης (Ctrl+F).
